# 拾财 Web 客户端

V2 需求的桌面浏览器客户端，React / TypeScript / Vite / Ant Design / ECharts。生产页面不预置账户、余额、收益或目标，所有业务内容来自当前已授权账簿空间。

## 开发与验证

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npm run format:check
```

Node.js 22。开发地址 `http://127.0.0.1:5173`，`/api` 同源代理到 `http://127.0.0.1:8000`。构建产物为 `dist/`，生产由后台同源提供，并对非 API 的客户端路由返回 `index.html`。

## 边界

- 登录依赖后台 session；写入带 CSRF 和幂等键。结果不明确的网络重试沿用原键，服务器确认后清除。
- 金额、价格、汇率和份额以字符串提交。账务计算在服务端，金额展示不经过 JavaScript Number；仅绘图坐标转换为数值，数据表保留原始精度。
- 空间切换重新挂载业务界面并使旧请求失效。记账草稿仅保存在浏览器会话，键包含空间 ID；草稿不会入账。
- 导入经历上传、字段映射、预览、人工确认。来源的“计划适配”不是机构原生格式已兼容；实际覆盖以后台适配状态与样本验证为准。
- 邀请注册与加入先预览共享范围。财务提交、冲正、账户初始金额与机构价格有确认步骤；计划到期与实账匹配分开。
- 低装饰模式和金额遮挡使用本地显示偏好。图表附可读数据表，私有附件与导出仍逐次检查后台授权。

## 结构

- `src/api.ts`：同源 API、错误、CSRF、未决请求幂等身份。
- `src/state.tsx`：空间上下文、响应失效控制及业务刷新。
- `src/components.tsx`：统一数据状态、精确金额、记录表单、财务确认、详情与冲正。
- `src/pages/`：7 个业务入口与设置；稳定路由均在 `/spaces/:spaceId/` 内。
- `tests/finance-client.test.mjs`：金额精度、幂等重试、空间隔离、错误与上传契约。

浏览器端权限控制只改善操作反馈；最终授权、金额验证、去重、事务以及版本冲突均由后台执行。
