# Wealth 个人与家庭财务管理系统

中文电脑网页端，统一记录银行、现金、基金、证券、期货期权、贷款和未来大额支出；从第一版支持多个独立用户或家庭空间、境内与港美资产及多币种。

**2.7.0 已于 2026-09-30 08:30（北京时间）部署到 [HTTPS 入口](https://124.223.23.76/)**。 基金申购支持先记申请、后记扣款与确认份额；可以记住每只基金的默认扣款账户，或明确使用账外资金。普通收支直接保存并可撤销；定投自动补录仍需明确开启，保留推算标记。
服务器入口：**[https://124.223.23.76/](https://124.223.23.76/)**。原管理员进入独立管理台；自己记账需另外建立普通用户和空间。可信 IP 证书自动续期与每日加密备份正常，尚未配置自动异地备份或失败告警。

本轮全量后端 **1,133 项及 12 子测试**通过，最终场内基金入口、分页及待确认补充回归 **60 项**通过；前端 **117 项**、生产构建及发布保护 **15 项**通过。服务器关键回归 **200 项**及两个生产空间 **23 项**只读查询通过，19个公网页面文件与验收版本一致。原数据、40张表、5个登录会话及调度状态保留。详见 [2.7.0 发布记录](docs/release-2.7.0.md)和[基金操作说明](docs/research/fund-workflows-2.7.0.md)。原 V2 全部 P0 尚有待验收项，下文保留历史版本证据。

## 本机启动

在项目根目录运行，浏览器打开 **http://localhost:8000**：

```sh
python3 scripts/local_dev.py start
python3 scripts/local_dev.py status
python3 scripts/local_dev.py stop
```

前置环境为 Python 3.12+、PostgreSQL 18、Node.js 22 和 npm；当前直接启动已在 macOS 实测。启动器创建或复用项目的 `.venv`、`.runtime/pgdata` 和私有文件目录，安装项目依赖、迁移数据库、构建网页并启动网页/API 与每 30 秒一次的待办及任务扫描。它不会安装全局软件或修改已有全局数据库服务。新电脑的依赖准备、可选端口与容器入口见 [RUNBOOK](docs/RUNBOOK.md)。

首次进入自行建立用户与账簿，不预置账号或演示资产。缺少 `.env` 时，启动器生成独立随机凭证；已有配置须移除占位密码并保持权限 `0600`。`.env`、数据库与账单原文件不提交 Git。`stop` 停止本项目网页和扫描进程，保留数据库和账本。

## 当前代码的导航与功能

投资交易集中到收支账本，收益日历与行情结算集中到分析复盘。资产与投资保留持仓、产品与账户两个主分组；财富规划保留两个。一级、二级、三级菜单支持个人排序、隐藏和恢复默认。

| 导航 | 当前代码中的功能 |
| --- | --- |
| 首页 | 昨日结算与今日估算净资产、现金指标、分类估值、紧凑市场自选、条件提醒；后三项可分别开关 |
| 资产与投资 | 持仓（买入、卖出、行内定投管理及全部定投入口）、产品与账户（含负债、核对） |
| 收支账本 | 全部流水、投资交易、基金分红核对、账单导入、月度预算、待办；银行与期货账户间转账明确标为银期转入/转出 |
| 财富规划 | 目标与方案（含预留、方案比较、文字策略）；现金流与还款（预测、周期收支、贷款与还款、业务日历） |
| 投资手札 | 正文、标签、关联事项、发布版本和复盘 |
| 分析复盘 | 收益日历、持仓配置、市场环境与提醒、行情与结算、收益指标与审计 |
| 管理中心（普通用户） | 空间成员权限、汇率、来源状态、私有文件与完整导出 |
| 独立管理台（仅管理员） | 用户账号、用户空间与代管、回收站及永久删除、数据源、配置参考、名词帮助、操作审计；不拥有私人账簿 |
| 代管数据管理（仅管理员） | 代管空间内的 22 类业务数据统一维护、账簿及成员资料编辑、关联影响预览、删除恢复与彻底删除、期初及持仓更正；保留审计 |

产品名称、代码检索默认先查服务端公共目录；点击“联网查找”才访问公开产品源。商品期权支持 `2701豆粕沽3300`、`m2701-P-3300` 等标准化输入，格式识别不等于已验证上市。指数用于市场观察，不能作为普通可买持仓。

基金渠道和证券账户的初始金额先记为机构留存资金；拆分已有持仓默认按当前市值分配，另存真实成本及份额。余额不足只从明确选定的同币种资金账户补差额，不自动寻找银行卡。若初始金额只填写了闲置现金，则使用“另行补录已有持仓”。现金宝如作为货币基金持仓，不会自动赎回成为现金。

已有持仓仍支持原买入日期、份额、成本和手工当前持有收益/市值。配置标签可以重叠，单一关联标签自动归集；多个重叠标签需指定唯一归属以免重复计算。目标权重由用户设定。标签历史采用固定当前份额回看正式价格，**不是实际历史组合收益**。净资产变化包含收支与资金流，**不等同于投资收益**。条件提醒支持回撤、单日涨跌、价格/点位及 AND/OR；示例模板默认停用，不会自动下单。

账务以不可变事项和分录为事实来源，数据库校验每个币种分别平衡；修改通过关联与冲正保留历史。基金申购费用进入管理成本，报告不会再扣一次。未知成本可以保留实际卖出与到账，但不会编造已实现收益。贷款本金减少负债，利息计入费用；冻结与预留的重叠部分不会重复扣减可安排现金。

计划默认到期产生待核对期次；基金定投可逐项开启按计划自动补录，登记假定已执行的扣款并在净值及规则齐备后推算份额，保留推算来源。未开启的计划仍需关联真实账单或人工确认后改变账本。系统**不会发起外部付款、银行扣款或证券交易**。未来 30/90/365 天预测与实际余额分开，互斥方案分别计算。期货期权以机构权益快照及其明确覆盖范围为主要核算依据，不宣称已实现交易所级逐笔结算复算。

通用 CSV/TXT/XLSX 导入已用合成样本验证，包括字段映射、预览、幂等、证据归并、错误行拒绝与部分提交续办。**喵喵记账、广发期货、银河期货、广发基金、易方达基金的专用适配仍为 `planned`**，尚缺真实脱敏样本；支付宝、微信、银行和港美券商也不能仅凭通用映射宣称已兼容。2.1 已接入公开行情参考源，具体范围及限制见[行情研究](docs/research/market-data-v3.md)。没有自动银行连接或自动机构账单拉取；汇率、机构结算和不支持产品的价格仍需录入。公开报价可能延迟，不能承诺全部市场逐笔实时。

已有持仓录入保存的是当前建账事实，不会倒造历史现金扣款或定投执行。基金正式净值与盘中估值分开，未收盘日 K 不进入正式价格。分红、红利再投、拆分和实际买卖须有对应记录；识别到分红/折算而缺实际记录的日期会保留缺口。手工“当前持有收益”属于该账户的持仓估值，不发布为共享产品价格。普通“记一笔”的备注/凭证说明可留空。

## 技术与验证

采用 React 19、TypeScript、Vite、Ant Design、ECharts；后端为 Django 5.2、PostgreSQL 18 的模块化单体。金额由后端 Decimal 与数据库 NUMERIC 处理；空间权限与 PostgreSQL 强制行级安全共同隔离数据，日常运行使用非 owner、无 BYPASSRLS 的数据库角色。前端编译产物由 Django 同源提供。

本次 2.5 本地及最终服务器镜像均通过 **673 项后端测试、12 项子测试**；前端 **35 项测试**、类型/格式检查和生产构建通过，运维脚本 **5 项测试**通过。浏览器验证独立管理、空间删除、可配置帮助、机构资金分配、基金日期与期货盘中展示；证据见[2.5 发布记录](docs/release-2.5.md)。运行环境为 Ubuntu 24.04、Python 3.13.15、PostgreSQL 18.6、RabbitMQ 4.3.6、Docker 29.1.3 / Compose 2.40.3，五个主服务健康。历史恢复演练的样本范围及尚未完成的完整验收继续保留。

初始化本地环境后，安装开发检查依赖并运行：

```sh
.venv/bin/python -m pip install -r backend/requirements-dev.txt
.venv/bin/ruff check --select E9,F63,F7,F82 backend scripts
.venv/bin/ruff format --check backend scripts
.venv/bin/python scripts/local_backend.py test pytest --tb=short
npm --prefix frontend test
npm --prefix frontend run typecheck
npm --prefix frontend run format:check
npm --prefix frontend run build
.venv/bin/python -m unittest discover -s scripts -p 'test_*.py' -v
.venv/bin/python scripts/test_restore_local.py
```

后端测试使用独立的 `wealth_test` 和真实 runtime 角色；恢复演练使用两个独立合成数据库，不写入用户主账本。已有验证覆盖财务算例、多租户隔离、导入幂等、后台重试、计划与贷款、私有附件及加密恢复。1 万行合成账单的服务端预览实测为 2.9631 秒，条件与边界见[验证记录](docs/verification.md)。完整结果和未通过项以[验收表](docs/development-status.md)为准，CI 配置存在不等于远程 CI 已运行。
