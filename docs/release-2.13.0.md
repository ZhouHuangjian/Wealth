# 2.13.0 个人聊天助手

本版在已部署的 2.12.0 基础上增加聊天助手，保留既有财务修复、登录会话、管理员代管规则和休闲角。2.12.0 已发布源码及发布记录一并纳入本次版本历史，2.13.0 已合并至 GitHub 主分支。

## 功能

管理员可为指定账号启用聊天助手；管理员与普通用户均可拥有自己的聊天页面。用户创建设备，将一次性展示的连接配置导入 Mac 相知，即可上传、查看和复制候选回复。设备可撤销，云端只存凭据摘要；聊天数据按个人账号隔离，财务空间成员不会因此共享聊天。

本次为首阶段：服务器保存和展示草稿，Mac 继续采集微信并生成回复。完整对话同步、云端远程控制和微信发送不在本版范围。操作见 [聊天助手说明](chat-assistant.md)。

## 数据变更

新增聊天权限、设备及草稿表，并扩展既有账号删除函数以清理该账号的聊天记录；不扩大财务数据删除范围，不自动执行账号删除。默认所有账号的聊天功能关闭，由管理员在页面配置。既有财务表、成员及密码无数据迁移。

## 运维与使用

生产 Compose 的构建目录已指向本次冻结的 `source/`，避免后续从 `/opt/wealth/backend` 的旧副本构建。运行时环境及私有数据卷保持原配置。旧镜像保存为 `wealth:rollback-before-2.13.0-20261011`；如需应用回退，可恢复发布目录中的 `compose.before.yaml` 并将旧镜像标记为 `wealth:local` 后启动三个应用服务。追加的 0013 可保留；出现数据保全异常时应先核验，不能直接开放写入或清库。

所有账号默认关闭聊天功能。管理员在“聊天管理”启用指定账号，该账号在聊天页创建设备并复制配置，再粘贴到本机相知的设置中。Mac 本地工作台已更新；采集、自动生成及自动同步保持暂停，由用户选定会话并开启。此阶段上传候选回复，不包含微信自动发送。
