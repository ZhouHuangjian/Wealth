# 2.13.0 个人聊天助手

本版在已部署的 2.12.0 基础上增加聊天助手，保留既有财务修复、登录会话、管理员代管规则和休闲角。GitHub 主分支尚未包含的 2.12.0 已发布源码及发布记录一并纳入本次版本历史。

## 功能

管理员可为指定账号启用聊天助手；管理员与普通用户均可拥有自己的聊天页面。用户创建设备，将一次性展示的连接配置导入 Mac 相知，即可上传、查看和复制候选回复。设备可撤销，云端只存凭据摘要；聊天数据按个人账号隔离，财务空间成员不会因此共享聊天。

本次为首阶段：服务器保存和展示草稿，Mac 继续采集微信并生成回复。完整对话同步、云端远程控制和微信发送不在本版范围。操作见 [聊天助手说明](chat-assistant.md)。

## 数据变更

新增聊天权限、设备及草稿表，并扩展既有账号删除函数以清理该账号的聊天记录；不扩大财务数据删除范围，不自动执行账号删除。默认所有账号的聊天功能关闭，由管理员在页面配置。既有财务表、成员及密码无数据迁移。

## 验证与发布状态

本地完整后端回归 1,527 项及 12 项子测试通过；跨标签身份保护补充后，30 项聊天专项测试再次通过。空测试库完成 0013 的回退与重新迁移。Mac 客户端完整 146 项测试通过，公开代码中的个人校准例句已替换为图书馆合成示例，相关 17 项测试复验通过。前端 178 项测试、类型检查与生产构建通过。

独立审查修复了跨标签切换账号后的缓存与写入归属问题：聊天响应携带当前账号标识，页面丢弃旧账号的迟到响应和凭据；Session 写请求需匹配预期账号，设备上传仍只认其独立凭据。两端使用合成数据完成真实 HTTP 上传与重复提交去重，不读取真实微信或财务数据。

服务器候选验证与发布尚在进行；正式提交、Linux 镜像测试及部署证据将在完成后补充。上述本地测试不表示已经上线。
