# 2.14.0 聊天设备远程管理

“我的设备”提供远程管理入口：在网页搜索并添加 Mac 微信联系人，调整会话采集、自动草稿与备注，以及本地模型和草稿生成配置。永久删除按钮适用于有效及已撤销设备，并清除关联云端草稿、远程配置快照和操作记录。

## 使用方式

1. 双击 Mac 桌面“启动相知”，在本地设置保存 Wealth 设备连接配置，保持“允许网页远程管理”开启。
2. 登录网页，进入“我的聊天／聊天助手 → 我的设备 → 远程管理”。
3. 在“聊天人员”搜索联系人并添加，再分别开启采集与会话自动草稿。新增会话默认暂停；生成自动草稿还需打开全局开关并先在本地配置好模型。
4. 在“本地配置”修改模型、生成等待、冷却间隔、每日上限、免打扰、自动草稿和同步开关。以“执行记录”完成回执及更新后的配置为准。

Mac 主动连接服务器，每次领取一个操作。请求有效期十五分钟；离线时等待，超时需重新提交。已执行操作有本地持久回执，网络重试不会重复执行。关闭本地远程管理会取消待执行操作；如果当时断网，重新开启前先补交停用通知。重绑、撤销、删除和账号停用均有独立的身份校验。

远程操作只生成草稿，不发送微信。接口地址、API 密钥、微信密钥、设备凭据和系统命令不能远程修改。仅同步允许的配置、已接入联系人元数据及显式搜索结果；不上传完整聊天正文、媒体或习惯档案。完成的远程操作记录保留三十天。Mac 本地聊天不受云端永久删除影响。

## 数据兼容

0015 在设备表新增空配置快照和最近轮询时间，新增设备操作表、必要运行角色权限与账号清理规则。不改动原有财务权限、登录密码、绑定凭据或草稿。字段具有兼容旧应用的数据库默认值，应用回退时可保留新增结构；不自动恢复用户随后主动删除的数据。
