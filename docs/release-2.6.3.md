# 2.6.3 今日收益与持仓展示

本轮依据用户提供的投资账本参考页面，完善首页收益分层与持仓列表。已于 2026-09-28 21:51（北京时间）保留数据部署。

## 行为

- 首页并列展示昨日结算净资产、今日估算净资产、今日估算收益。收益可展开查看项目、原币与折算金额、实际数据日期、计算基准和缺失原因。净资产变化单独展示，并折叠统计说明。
- 当日收益使用当天有效价格与可比基准，扣除买卖净投入、计入已记录分红；不把新入金、申购在途本金、累计浮盈或期权参考市值误算为今日收益。同日正式数据优先于参考行情，跨越缺失交易日时不把多日涨跌并成一天。
- QDII 最近正式报价日单独保留实际日期；没有今日行情或基准时显示待补全，已知部分不冒充完整总额。外币投资按当日可用汇率折算原币收益，不计独立汇兑损益。
- 持仓默认展示产品、最新持仓价值、持有收益、今日估算收益与操作。支持持仓置顶、名称/账户/同币种金额排序、标签搜索；“显示设置”支持列显隐、调序和固定，设置按登录用户与空间隔离，仅当前浏览器生效。
- 持仓顶部按当前筛选、原币分别汇总。机构权益覆盖明细与期权参考不重复加总，保留数据缺口与原有买入、卖出、定投操作。
- 复用现有两位小数展示，计算保留原精度；隐藏金额时同步遮挡收益率、颜色与明细。未增加没有数据基础的分时曲线、周/月/年度收益。

## 数据与边界

无数据库迁移，保留现有账号、空间、业务记录、会话、文件与后台任务。显示设置只保存列配置、排序和记录标识，不在浏览器保存财务金额。

日收益依赖真实账簿、净值、市场日历和完整权益范围。旧快照跨休市且缺交易日历、缺中间交易日行情、尚未核对的持仓等均保留缺口；不会自动补造财务事实。参考截图的待确认笔数没有现成可靠字段，本轮不从份额差额推算。
