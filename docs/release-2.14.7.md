# 2.14.7：完整历史、远程存档与模型中心

已接入的微信会话可读取这台 Mac 当前可用的全部历史。首次读取先展示最新内容，再分批补齐早期记录；同一消息自动去重，断点保存在本机。手动「读取历史」会在后台续读至完成，不会开启长期监听。微信后来下载了更早的记录，可使用「重新扫描历史」。历史补读不触发自动草稿或批量媒体识别。

回复、指定消息分析、对方档案和记忆整理都纳入完整已读历史。分析某条旧消息时只使用截至当时的上下文；长历史按字节分段整理并逐级合并，结果仍属于可能遗漏细节的模型摘要。整理缓存按联系人、原文和模型分别保存，更换模型后重新处理，切回原模型可复用匹配的缓存。已知尚未补齐的会话会提示先完成读取。完整输入覆盖不意味着保存每个细节：档案和记忆继续提供精简条目，原消息另行保留。

「模型中心」集中管理回复、图片、语音、意图与好感分析、档案与记忆的模型分工。各功能仍可选择不同模型；联系人页面统一进入「模型设置」，可跟随默认或覆盖回复、分析、记忆型号。图片和语音继承全局型号，自动处理开关按联系人设置。多模型回复保持草稿比较和人工选择。

开启网页远程管理后，Mac 将已读消息全文、现有解析文字和分析结果分批存入绑定的 Wealth 服务器。服务器的联系人目录与历史翻页独立于近况预览，不再把每人最近 30 条作为存档上限。丢失响应时重试同一批次，确认后才推进进度。原始图片、语音、微信密钥、模型密钥和本地习惯档案不随历史上传。离线时可查看已同步内容。

页面区分已读取、正在补齐和同步状态；分页是展示方式，分批是传输方式。尚未下载到 Mac 的微信记录无法由本工具恢复；媒体只有占位符时也不会虚构内容。单条消息若超过接收大小，会保留原文并报告未同步，不会截断后确认成功。此前保留的旧分析可标为待更新，重新分析仍由个人开关和主动操作控制。

服务端增加四张聊天历史表及账号删除清理，沿用账号和设备隔离、撤销权限与命令校验。永久删除设备会连同历史存档删除。更新保留资金业务数据和已有聊天配置；发布前执行备份、迁移守护、客户端及完整服务端回归。
