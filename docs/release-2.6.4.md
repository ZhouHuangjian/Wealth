# 2.6.4 定投自动补录

用户已明确选择：按计划视为已成功扣款，自动记入账簿；净值公布后推算份额，保留推算来源并允许排除失败日期。2.6.4 已于 2026-09-28 22:19（北京时间）完成保数据部署，22:19 完成公网及生产只读验收。

每个适用的场外基金定投计划可独立开启自动补录，选择生效日期、费用依据与失败/暂停日期。未开启的原计划继续采用原方式。自动流程只改变本系统账簿，不操作外部银行卡或基金账户；股票、场内 ETF 与衍生品缺乏实际成交价格，继续走现有记录方式。

自动扣款与份额推算分两个阶段：符合共同开放日、在生效范围内且资金充足时登记扣款并完成对应待办；对应正式净值、预计确认日期及费用条件满足后推算份额。缺失数据、资金不足、关联含糊、已冲正或重复风险保留待处理状态。重复后台执行不得二次扣款或二次增加份额。

暂停或排除日期不应静默删除已经记入账簿的记录。已经补录后才发现实际扣款失败，需要从实际记录核对和更正。推算来源保留到交易记录、持仓和自动化状态中。

入口：资产与投资 → 持仓 → 定投（或更多 → 全部定投计划）→ 编辑 → 按计划自动补录。补录设置默认折叠，默认从今天起、费用暂不确定；可选已确认零费用或每期固定费用，并明确指定持仓账户。保存后由后台每五分钟检查，进度抽屉可立即检查。未开启的旧计划不改变既有账簿。

基金份额由该申购日的已公布正式净值推算，默认份额精度两位，可尊重产品配置；价格、预计确认日期与费用不足时维持等待状态。开启前需确保付款账户有可用余额；本轮不跨未知账户自动补足资金，也不模拟实际机构支付。单次检查最多500期并保存轮转游标，页面只列最近500期。停止自动补录不会撤销已记录事项。

后续基金扣款账单若发现同账户、同日、同币种同金额的自动补录，导入页面会提示核对：可关联原事项而不再次扣款，或明确确认这是另一笔独立交易。份额推算来源不会因仅关联扣款凭证而升级为机构实际确认。
