# 2.5 发布与验收记录

状态：**2.5.0 已于 2026-09-27 21:37（北京时间）部署到 [HTTPS 入口](https://124.223.23.76/)**。本轮按用户要求清空旧普通用户、所有空间及业务数据；原平台管理员账号和密码保留，管理员不再拥有私人空间。 清理前已完成服务器及本机加密备份验证；上一版记录见 [2.4 发布记录](release-2.4.md)。

## 机构资金和已有持仓

- 基金公司、券商等明细账户的初始金额暂作为留存资金。新增已有持仓默认选择“从机构已有资金中分配”，按手工核对的当前市值减少留存资金，另存原取得成本与份额，不把历史盈利当作入金或消费。
- “另行补录已有持仓”适用于初始金额只填了闲置现金的情况，不扣账户余额。旧 API 省略 `funding_mode` 时仍采用此兼容行为。
- 机构资金不足时只从明确选择的同币种资金账户补足不足部分，保存补资转账及关联持仓。冻结资金、回填日期及其后已记支出均纳入校验；失败整笔回滚。
- 真实新买入仍使用买入、申购扣款和份额确认流程。现金宝如已作为货币基金份额建账，不会被当成可直接扣减的现金；货币基金赎回转购仍应根据实际机构流水分阶段记录。
- 总额 100 元、成本 80 元、当前市值 81.82 元的例子：机构留存 18.18 元、基金 81.82 元、总资产仍为 100 元，基金持有收益 1.82 元。

## 数据日期与估算口径

- 已有持仓分别保存份额核对日期、净值或行情所属日、查看时刻及正式/估算/未核实口径。手工数据不会仅因今天录入就成为今天的正式净值，也不会凭空补出昨天的持仓。
- 正式基金净值按来源的实际日期使用；晚间、周末、节假日、QDII 的发布延迟都不通过“当前时间减一天”猜测。未知日期须保留未核实状态。
- 期货账户权益区分正式结算、盘中权益、未核实。盘中权益可用于估算，不替代正式结算；合约实时价格、保证金、合约名义金额不能再叠加到已包含它们的总权益。
- 对明确选择的交易日历，且间隔日期均已确认休市的情况，允许沿用最近正式结算并展示实际日期。未知市场、日历覆盖外或产品临时暂停不自动断言为已结算。
- 首页展示昨结与今日估算，并展开各项来源、实际数据日期、口径和查看时刻。今日估算可混合正式数据与盘中估值，缺失部分保留提示。

## 独立平台管理与名词帮助

- 管理员登录进入独立管理台，没有私人空间、私人记账入口或成员身份。普通用户与管理员身份在创建时确定，不互相转换；管理员显式进入用户空间进行代管，并保留真实操作人审计。
- 管理员可以创建和管理账号、配置和代管空间、删除用户，将空间移入回收站或恢复，并永久清理回收站空间及附件。删除账号不连带删除共享空间；仍是使用中空间唯一所有者时须先移交或回收空间。
- 永久删除需要输入准确名称、确认影响、校验版本和幂等。数据库迁移 0010 使用受限清理函数，运行角色仍无超级用户或绕过行级权限；普通账务修改仍必须冲正。
- 管理台“名词帮助”支持新增、编辑、隐藏内置词、删除自定义词、恢复默认，普通页面悬停、点击和长按采用相同词库。说明按纯文字渲染，修改具有版本校验与审计。
