# 2.9.0 基金收益日期、空仓默认与日夜主题

## 基金收益

正式基金收益按净值归属日进入收益日历。QDII 延迟公布时，“最近净值收益”保留实际日期，不叠加到当天估算收益。首页明细和持仓中，当日收益尚不可计算时可查看最近净值收益；鼠标悬停区分净值归属、来源公布和系统获取时间。

已确认申购使用可核对的成交净值日回溯收益，T+2 确认不会把此前多日收益集中记在确认日。扣款日、确认日、资金在途与原始流水保持不变。回溯要求关联申购存在且日期匹配；异常记录显示待核对。正式净值与推算份额分别标明来源。日历和首页采用一致计算规则。

参考基估宝的审计和接口现场对照见[QDII 收益归属研究](research/fund-qdii-return-dates-2.9.0.md)。未复制参考项目的 AGPL 源码。保留现有公开数据适配器，不接入无法验证估值模型与基准日期的自建 QDII 数据表。

## 空仓账户

对于具备权益基准、期间未记录持仓或申购在途的期货及其他理财账户，延续已记录现金权益并默认无结算盈亏。无明确限制时估算全部可提取，保留“根据已记录空仓情况推算”的来源。已填可提取金额、冻结或提现限额仍优先；期间交易后清仓不能据此抹去盈亏。该变化只影响投影，不新增余额或结算流水。

## 日间与夜间

日间使用大耳狗的蓝白与长耳意象，夜间使用库洛米的紫黑、粉紫与尖耳意象。顶部提供切换入口，显示偏好可选择日间、夜间或跟随系统；按登录账号在当前浏览器保存。表格、表单、弹窗、图表、管理与登录页统一适配。价格涨跌保留财务语义。
