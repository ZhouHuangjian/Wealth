# 2.14.5：远程联系人配置与模型设置整理

绑定的 Mac 运行相知后，Wealth 的聊天助手可以分别调整联系人的比较回复模型、自动识图、语音转写、意图分析、好感估计及记忆开关，也可以选择独立的分析与记忆模型。联系人姓名旁显示好感估计百分比。

「档案与记忆」支持主动读取、手动增删改资料和记忆条目、编辑摘要及待续话题、请求模型生成档案或压缩对话。操作在 Mac 执行，模型继续参考个人习惯档案和本地记忆，人工修改优先保留；原始聊天与媒体不上传远程管理接口。远程页面使用配置版本校验，避免旧表单覆盖 Mac 上的新修改。

本地设置分为回复、媒体、分析与记忆、设备与同步四组；个人信息处理按功能分组。Codex 候选来自本机可用模型目录，千问候选只在千问服务下出现，切换服务不沿用其他服务的模型名称。当前 Codex 接入支持文字和图片，语音由千问或支持音频输入的兼容服务转写，随后可由 Codex 生成回复。

网页只调整模型与功能选项，API 地址、密钥及模型授权保留在 Mac。本扩展沿用设备绑定、账号隔离、撤销、命令过期、回执幂等和结果清理机制，兼容原有 v1 客户端，不新增数据库迁移。远程操作不会发送微信消息。

发布基于线上 2.14.4 提交 `1eb1d67ba9277c440be976011be1b30c99b74d9b`，保留现有资金与收益功能。客户端协议及远程编辑回归、115 项后端远程测试、两端类型检查与构建通过；42 个真实本地客户端合成快照和 21 条命令回执通过后端严格校验，覆盖全部 14 类操作。生产构建及完整 Linux 回归以冻结提交为准。
