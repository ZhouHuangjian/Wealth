# 2.10.0 基金正式净值与实际交易核对

本版增加广发基金、易方达基金、摩根基金的公开正式净值来源，并把实际申购确认记录与已有推算记录关联起来。公开行情不包含个人持仓或成交信息，净值一致也不能证明某笔定投实际扣款成功。

## 使用入口

| 入口 | 用途 |
| --- | --- |
| 独立管理台 → 数据源 | 开关、调整来源顺序；为 Tushare、理杏仁保存或移除访问 Token |
| 分析复盘 → 行情与结算 → 自动行情 | 查看净值日、数据质量；展开某行查看各来源、公布时间、获取时间及被隔离的净值 |
| 收支账本 → 账单导入 → 基金交易核对 | 上传 CSV/XLSX，选择持仓账户并映射列，核对已有申购 |

公开来源默认启用；旧配置里已经明确停用的来源继续停用。订阅来源默认停用且未配置；保存 Token 不代表已获得服务商权限或额度，需在数据源中启用后才能取数。Token 不回显，也不保存在浏览器存储；数据库保存加密值，审计仅记录操作与版本。

## 净值处理

- 新官方适配范围为境内六位代码、已核实的人民币普通基金份额，包含 QDII；货币基金万份收益、外币份额及其他公司的官方页面不冒充已适配。
- 按净值归属日选取最新有效正式值，再按配置顺序选同日一致的来源。较旧响应不覆盖较新值。只有一个可用来源时注明“单一来源”。
- 同一天出现正式净值差异时，保存来源详情并隔离该日。已有原始价格不删除，自动份额、正式收益、配置历史及提醒不再采用隔离值；持仓保留可用的历史值并显示缺口。
- 单源恢复不自动解除已发现的差异；至少两个不同来源对同日净值一致后才解除。已经生成的交易不会因公开行情变化被静默改写，需按实际机构记录核对。
- 净值归属日、公布时间、获取时间分别保存。来源未提供逐条公布时间时留空，不把刚刷新解释为今天正式收益。盘中估值独立保留，不能替代正式净值。
- 成功的公共响应缓存 10 分钟，有条数与容量上限，相同请求并发合并；缓存保留首次获取时间。异常不缓存为零值。新来源是不同服务接口，不承诺它们底层原始数据完全独立。

## 实际基金交易核对

首次导入为账户设置字段映射，后续复用。标准字段包括基金代码、申请/扣款/确认日期、申购金额、确认份额、确认净值、手续费、订单号、币种；不知道的字段可空，费用未知不会补成零。这是标准文件映射，尚未宣称兼容任何机构的原生导出格式。

完整字段与唯一已有申购一致时，可以一次绑定全部匹配记录，不新增买入、不重复扣款，也不改变份额。只有实际扣款资料时只能证明扣款，不能把推算份额标为机构已确认。同日同额只产生候选；来源订单号不同的交易不能被合并。

有差异的记录展开显示前后值与资金影响。完整的实际确认资料可以更正自动推算记录，要求填写原因；原始事项通过冲正和替代链保留，后续定投扫描跟随替代链，不再次生成原扣款。有后续持仓变动依赖时，需要按逆序处理，不能批量覆盖旧成本。实际交易记录仍从交易记录入口更正。

未匹配记录保留待处理，并提供基金买入入口；此版核对入口不会凭一份未知文件直接新建交易。部分处理后可“重新核对”，已处理的行不会重复入账。重复请求有幂等保护，过期预览要求刷新；整批账务更正和来源关联在同一事务内完成。

实际成交净值不自动成为公共正式净值。撤销仅有来源绑定的批次会撤回证据；含账务更正的批次需从交易记录按依赖处理，不能通过删除文件反向抹掉资金变化。

## 验证范围

2026-10-06 实际查询：广发 `270042` 的 2026-09-29 净值为 `8.3418`，易方达 `020602` 的 2026-09-30 净值为 `1.0826`，摩根 `019172` 的 2026-09-29 净值为 `1.7899`，与当时东方财富响应相同。官网历史查询分别覆盖 20/21/21 条样例记录；样例成功不代表持续可用性或全部产品均已验收。

Tushare、理杏仁按官方接口契约实现，并用合成响应测试；本次没有订阅 Token，未执行授权后的真实取数。真实机构私有账单仍需用户导入；没有基金公司个人账户登录、交易授权或自动银行扣款。

发布与最终验证结果在完成后补充。过程证据保存在被 Git 忽略的 `.runtime/v210/` 与 `.runtime/v2100/public-probes/`，不会把测试账号、Token、账单或生产备份提交到仓库。

## 来源与维护

- [广发基金官网](https://www.gffunds.com.cn/)：公开基金身份、最新及历史净值。
- [易方达基金产品页](https://www.efunds.com.cn/fund/020602.shtml)：份额身份与官网净值查询。
- [摩根基金官网净值数据](https://www.cifm.com/images/fund/net_valuemeta_2716.xml)：份额、币种与净值日期。
- [Tushare 基金净值](https://tushare.pro/document/2?doc_id=119)、[理杏仁基金净值接口](https://www.lixinger.com/api/open-api/html-doc/cn/fund/net-value)：可配置的订阅接口。

来源适配在 `backend/wealth/fund_sources.py`，选择策略在 `provider_policy.py`，冲突隔离在 `market_quality.py`，凭据在 `provider_credentials.py`，基金账单核对在 `fund_reconciliation.py`。页面说明分别在 `ProviderCredential.tsx`、`QuoteQualityDetails.tsx`、`FundReconciliation.tsx` 与 `market-quality.ts`；可配置名词帮助仍通过管理员的“名词帮助”维护，不会覆盖这些业务校验提示。

数据库无新增迁移。保留原 `DJANGO_SECRET_KEY`，否则原 Token 密文无法解开。需要轮换时，把旧密钥放进私有环境变量 `DJANGO_SECRET_KEY_FALLBACKS` 的 JSON 数组，重启服务，逐一重新保存来源 Token，使其使用新密钥；完成会话与其他签名数据的过渡后才能移除旧密钥。不要提交密钥、密文或备份到 GitHub。现有已加密备份继续包含这些配置，但恢复时也必须持有相应环境密钥。
