# 2.13.1 设备配置与管理员聊天入口修复

本版修复设备添加后仍显示首次绑定提示、配置错过后无法再次获取、管理员个人聊天入口不够明显三个问题。

## 行为变化

- 管理工作台固定显示“我的聊天”，可直接管理本人的设备与回复草稿，无需财务空间或代管授权。“聊天管理”继续负责按账号开启功能。
- “我的设备”显示等待 Mac 连接、已验证连接或已撤销；草稿空态区分没有设备、等待连接和等待草稿，旧列表响应不能覆盖刚完成的设备变更。
- 上传地址持续可见，设备配置可以反复查看、复制或下载。新凭据按账号及设备加密保存，列表不返回凭据；查看配置不会使原配置失效。
- 2.13.0 旧设备没有可解密的凭据，可主动重新生成配置：旧配置失效，设备与历史草稿保留。重新生成后需在 Mac 粘贴新配置，此后可重复获取。
- Mac 保存 Wealth 配置后验证一次，也提供“验证连接”按钮。验证只核对设备凭据并更新最近验证时间，不上传聊天或草稿；失败仍保留已保存配置，不开启自动处理。

## 兼容与验证

0014 仅在设备表新增空密文字段，保留数据库默认值以兼容旧应用回退；不回填或轮换已有令牌，不修改已有设备、用户、草稿或财务数据。私有配置接口保持本人 Session、CSRF 及账号标识校验；连接验证仅接受独立设备凭据，停用账号、关闭聊天及撤销设备都会阻止连接。

本地 40 项聊天专项、前端 184 项测试、Mac 155 项测试与两端构建通过。已验证加密隔离、回取稳定性、旧令牌兼容、轮换失效、回滚兼容插入、跨账号保护、超时及旧响应处理。完整合成界面验收、固定 Linux 镜像回归和正式发布记录将在部署完成后补充；本节不代表已经上线。
