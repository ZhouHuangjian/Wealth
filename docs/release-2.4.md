## 本轮变化

| 用户需求 | 当前实现 |
| --- | --- |
| 基金分红自动化 | 「收支账本 → 基金分红」可手动检查或开启定期检查，缓存公开公告、匹配账户与登记日已记录份额、估算分红，并生成待确认事项。核对实际记录后确认现金分红、红利再投或关联已有流水。 |
| 删除空间 | 空间所有者或平台管理员可输入完整名称，将空间移入回收站。停止访问和后台更新，保留账目、成员和证据；恢复后重新开放，旧邀请码仍失效。 |
| 新建空间后邀请注册 | 新建空间时可同时生成邀请码，默认查看权限、7 天有效、一次使用。新用户在注册时填写；已有用户可使用邀请码加入。既有空间仍可在成员管理中选择角色和有效期生成邀请。 |
| 将其他用户的配置作为参考 | 平台管理员选择来源用户及其有效空间，预览后发布配置快照；平台登录用户可预览并选择采用部分配置。支持上下架，不自动同步来源后续变更。 |
| 管理内容集中 | 独立的「管理中心」集中空间成员、邀请、回收站、配置参考、导航偏好、名词帮助、汇率、适配状态、导出和隐私设置。平台管理员可进入「平台管理」维护用户、空间、配置参考、来源和审计。 |
| 调整菜单按钮过于显眼 | 各组菜单使用小型设置图标，统一调整入口保留在「管理中心 → 导航偏好」，支持键盘访问。原有排序、隐藏和恢复默认能力保留。 |
| 新手看不懂术语 | 内置 122 个术语及别名，覆盖账户、收支、投资、行情、规划和管理。已接入的标题、表头及表单标签支持悬停、点击、触屏长按和键盘说明；管理中心提供可搜索的名词目录。 |
| 新增账户资金未出现在首页 | 统一开户与首页计值口径，明确显示金额来源、未知金额与缺少汇率的原因；普通账户期初、机构总权益与历史已记录资金分别处理。 |

## 分红自动化的边界

自动发现目前覆盖**境内人民币场外基金**的公开现金分红公告，不等于从机构取得个人到账记录。货币基金每日收益、ETF 与股票派息、境外份额和其他币种暂不在自动发现范围；原有手工记账仍可使用。

参考金额按登记日已记录份额计算。若用户在登记日以后才补录存量持仓，系统不会把当前份额倒推成历史权益，而是保留“份额待核对”。现金确认使用实际到账日期、税费前金额及实际税费；再投确认使用实际确认份额与净值。

已经导入或手工录入的分红可以关联原流水，不重复增加现金或份额。一个账本事项只能对应一个确认关联；同一公告的修订更新原待确认事项。确认写入具有版本与幂等保护，撤销仍使用冲正保留历史。

定时检查默认关闭；资料缓存和后台检查不自动扣款、交易或生成已实现收益。来源不可用时保留已有缓存并展示失败状态。来源范围、公开探针与处理细节见 [基金分红研究](research/fund-dividends-2.4.md)。

## 空间与配置共享

本版删除是可恢复的空间停用，不是物理清除数据。删除与恢复检查最新用户状态、空间所有者或平台管理员权限、当前版本；删除额外要求名称确认。已删除空间不出现在常规空间列表，不能继续访问账务或私有文件，也不继续执行后台刷新。恢复不会使已撤销的邀请码重新有效。

配置参考的分享范围为个人业务菜单、首页显示开关、标签名称/颜色/目标占比，以及公共目录中可识别的市场自选。它不复制银行账号、余额、交易、持仓数量、原始文件、私人笔记、账户关联或来源空间内的记录 ID；普通预览不暴露来源用户和空间 ID。发布前仍需检查自定义标签、模板名称与说明是否适合向平台登录用户共享。

采用标签与自选只增加缺少项，已有同名标签或同一产品自选保持原设置。新增标签与已有目标权重合计不能超过 100%；冲突时整个采用操作回滚。选择个人菜单或首页显示会替换相应设置，个人菜单影响该用户的全部空间。查看成员不能采用；编辑成员可调整自己的导航，账簿共享配置仅空间所有者或协助管理的平台管理员可采用。

## 账户与净资产修复

- 银行等明细账户的开户金额保存为期初事实，从金额对应日期计入首页。显式确认的零余额仍保留日期与账务依据。
- 今天录入的期初不会成为昨天余额的证据；昨日无可汇总记录时显示待补全，净资产变化显示暂不可比。
- 期货、期权以及选择机构权益计值的账户，开户录入的是机构客户总权益快照，不另生成一笔同额现金入金。开户需填写覆盖说明，可记录期权包含情况与可提取金额；未核实的覆盖范围明确标为已知部分。
- 旧版机构账户若只有期初现金或资金流水、没有总权益快照，首页显示已记录资金部分并提示补核机构总权益，不把它归零或冒充完整权益。补充总权益后使用该快照，不与旧期初重复相加。
- 完全没有可用权益记录时不以零填补。外币金额仍显示原币，缺少折算汇率时不猜测本位币金额。归档账户不抹除历史资产。
- 已有账务、持仓或机构权益的账户不能直接变更账户类型、币种和计值方式，以免改写已有金额含义。
