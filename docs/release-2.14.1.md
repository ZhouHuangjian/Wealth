# 2.14.1 估值与收益一致性修复（候选）

2026-10-13候选：修复首页估算收益间歇消失、缺数无清楚出口，以及持仓/净资产/收益日历之间的相关计算差异。**尚待最终验收与部署核实**，本页不能证明线上已运行2.14.1。
