# 2.5.5 期初日期更正与档案恢复

状态：**已于 2026-09-28 01:15（北京时间）部署到 [HTTPS 入口](https://124.223.23.76/)**。本次保留所有现有生产用户、空间、账目、会话和附件；数据库仍为 `0010_independent_administration`，无新增迁移。

## 本轮变化

账户可查看期初金额、日期及可更正范围，并填写原因更正日期。现金期初通过冲正重录，机构权益通过追加替代观察处理；金额、币种和权益范围保持原值，旧事实及审计保留。更正不能越过已有资金、持仓或权益记录的日期约束，也不改变持仓买入日期。

账户与投资产品增加删除影响预览及已删除列表。未使用产品、没有记录或只有可信开户期初的账户可删除；真实交易、持仓、导入、计划、期次及其他关联依赖会阻止删除，已冲正的业务历史同样保留。删除后从资产统计、产品选择及后台行情更新中排除，不清除原始记录；可恢复，并保留删除和恢复审计。恢复产品前须先恢复关联账户。

删除及日期更正均要求当前档案版本、账簿版本和幂等键，服务端在事务内重新校验。查看者不能写入，跨空间引用拒绝。收益计算的显式账户集合与资产估值采用一致的未删除账户范围，避免删除账户后留下虚假的期初投入或亏损。

接口与错误处理见 [API 契约第 18 节](api-contract.md#18-255-期初日期更正与可恢复删除)。可恢复的档案删除不等同于平台管理员永久清理空间。
