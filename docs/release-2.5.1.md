## 使用方式

在“资产与投资 → 新增投资产品”选择“期权”，确认产品及所属账户后，可同时录入期权持仓：

| 字段 | 填写口径 |
| --- | --- |
| 买卖方向 | 买入持仓或卖出持仓；与看涨、看跌合约类型分开 |
| 手数与合约乘数 | 手数为正整数；乘数使用已识别规格或人工核实的值，未知时不默认为 1 |
| 开仓均价 | 当前这笔持仓建立时的平均成交报价，不是行权价或总金额 |
| 当前持仓总市值 | 全部手数的权利金市值，填非负金额；市值为 0 时允许保存 |
| 开仓日期与市值日期 | 根据真实记录填写，不用录入时间倒推交易日 |
| 结算价及结算日期 | 可选；填写结算价后须选择其实际对应日期，0 也是有效价格 |

只添加自选产品时，可以不同时录入持仓。已保存的期权参考持仓在“我的持仓”中查看和更新；修改保留版本及操作记录。同一账户、同一合约、同一买卖方向使用同一份当前持仓记录，不重复新增。

## 金额与收益口径

开仓权利金金额＝开仓均价 × 手数 × 合约乘数。买入方向的毛浮动盈亏＝当前持仓总市值－开仓权利金金额；卖出方向相反。这里没有扣减手续费等费用，不作为已实现收益、今日收益或正式结算盈亏。

例如手工录入开仓均价 100、2 手、乘数 10、当前总市值 2400，则开仓金额 2000，买入方向参考毛浮盈 400，卖出方向为 -400。若选填结算价 110，其对应的结算参考价值为 2200，保留独立日期，不覆盖当前总市值。

期权参考持仓不生成资金分录或证券订单，也不把市值再次加到已包含期权的机构总权益。缺少包含期权的完整机构权益时保留核对提示。关闭参考记录不等于确认平仓成交、到账或已实现收益；这些仍须按实际机构记录核对。

产品资料与持仓参考在同一提交中保存；错误时整体回退。多用户并发修改须校验版本，同一请求重试不会重复创建持仓。普通基金、股票的已有持仓和机构资金分配流程继续采用各自原有口径。

价格、手数与乘数分别录入的口径参考大商所[豆粕期权业务指南](https://www.dce.com.cn/dalianshangpin/resource/cms/2017/04/%E6%9C%9F%E8%B4%A7%E5%85%AC%E5%8F%B8%E8%B1%86%E7%B2%95%E6%9C%9F%E6%9D%83%E4%B8%9A%E5%8A%A1%E6%8C%87%E5%8D%97%281%29.pdf)。产品实际合约规格以当前机构及交易所资料为准，此版本不新增自动交易、自动结算复算或真实机构账单适配。

## 基金金额不一致时怎样录入

机构页面可能同时展示总资产、持有份额、可用份额和按另一范围计算的持仓收益。仅有这些数字时，不能把可用份额当成已确认份额，也不能把总资产与不同范围的成本直接相减。

例如截图中资产 361.41、成本 345，对应直接计算值 +16.41；机构显示的收益为 -3.60。318.98 × 1.0703 ≈ 341.40，341.40 − 345 ≈ -3.60，剩余部分约 20 元。这说明范围存在差异，但尚不能证明这 20 元的确认状态。系统不会自动拆成申购在途，也不会把成本倒推改成 365.01。

新录入时可补填“机构显示的持仓收益”和对应净值。市值减成本与机构收益，或份额乘净值与市值，相差超过 0.02 时会提示核对，默认阻止提交。如果暂时无法确认范围，可明确选择保存为“待核对”，保留填写的份额、成本和市值；主收益不再显示为确定盈利，机构收益和原计算值分别保留。

已有记录在“资产与投资 → 持仓 → 该行更多操作 → 核对机构数据”中填写机构收益、净值及其日期，也可以填写可用份额和备注作为资料。这里不会产生扣款、买卖或修改成本，只建立核对记录。机构收益不会作为某一天的收益加入收益日历。

如果查明是份额、成本或取得日期录入错误，可使用同一菜单里的“更正录入”。目前只支持没有后续实际持仓变动、且有固定录入市值的存量持仓；原账户、产品、核对日期、市值和资金分配保持不变，更正保留旧记录与原因。涉及后续交易、估值范围改变或尚无法拆分的在途金额，须先核对原始交易资料，不能用更正入口重新扣银行卡或凑出收益数字。
