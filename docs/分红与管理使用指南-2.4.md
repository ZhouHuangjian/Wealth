# 分红与管理使用指南 · 2.4

本文对应已于 2026-09-27 20:35（北京时间）上线的 2.4.0。发布证据见 [2.4 发布与验收记录](release-2.4.md)。

## 自动检查基金分红

进入 **收支账本 → 基金分红**。先在系统中录入基金及对应账户的持仓，再点击「检查分红公告」；若希望持续检查，打开「定期检查分红公告」。检查由后台完成，可以等待页面更新或点击「刷新结果」。

系统会展示基金、账户、权益登记日、除息日、公告发放日、每 10 份分红和估算金额。比如登记日有 1000 份、每 10 份分红 0.20 元，参考金额为 20 元。**这是参考值，账户不会因为查到公告就增加 20 元。**

取得基金平台或机构实际记录后，点击「确认分红」，选择对应处理方式：

| 实际发生的情况 | 如何处理 |
| --- | --- |
| 分红以现金到账 | 选择「现金分红：金额到账户」，填写实际到账日期、税费前金额及实际手续费/税款，核对后确认。 |
| 分红转换成新基金份额 | 选择「红利再投：增加基金份额」，填写实际再投确认日期、机构确认的份额和净值，核对后确认。 |
| 账本里已经有这笔记录 | 点击「核对已有流水」，核对日期、金额和基金，选择「关联已有分红流水」。关联只建立对应关系，不再记一笔。 |

若系统列出可能对应的已有流水，会优先要求核对关联，避免重复。导入时没有指定基金的现金分红也可能被列为候选；必须确认它属于当前这只基金。若候选都不正确，先核对账本中的产品、日期和金额。

出现「份额待核对」，通常是登记日没有足够的持仓记录。今天补录当前持仓不代表能确定以前某天持有多少份额，请以机构记录核实。已确认的记录若填错，应在账本中冲正，再回到分红事项重新核对。

本版自动发现支持境内人民币场外基金。货币基金每日收益、ETF 或股票派息、境外及其他币种份额暂需手工处理。检查失败不代表没有分红，可以稍后重试或查看机构记录。系统不会代你操作银行或基金账户。

## 新建空间并邀请其他人

空间是一个独立共享账簿。需要与家人共同使用的账目放在共同空间，需要保密的账目和笔记放在另一私人空间。

1. 在空间切换菜单选择「新建账簿空间」，填写名称与本位币。
2. 需要邀请他人时，勾选同时生成邀请码；保存后复制显示的邀请码。
3. 将邀请码提供给准备加入的人。此入口生成的码是**查看权限、7 天有效、只能使用一次**。
4. 新用户在登录页点击「持有邀请码？创建账户并加入」，填写用户名、密码和邀请码，核对空间名称与角色后注册。已有用户通过「使用邀请码加入」进入。

邀请码提供的是整个目标空间的相应访问权限，不只是某一个账户。请确认对方应当看到这个空间的账目和笔记。

已经建好的空间可以在 **管理中心 → 空间与成员 → 邀请成员** 生成新邀请码。这里可选择查看、编辑或空间所有者角色及有效天数；需要记账的人可授予编辑权限。不要把空间所有者权限当作普通查看权限使用。

## 删除空间与恢复

进入 **管理中心 → 空间与成员**，在管理操作中点击「删除当前空间」。输入完整空间名称后，点击「移入回收站」。空间所有者和平台管理员可执行，普通编辑或查看成员不能删除。

空间删除后，所有成员停止访问，后台自动更新也停止；账目、成员和已保存的证据仍保留。可在「空间回收站」点击「恢复空间」。如果已经没有可访问空间，空间选择页面仍提供恢复入口。

恢复后原成员与账目恢复可用，但**旧邀请码仍然失效**。需要邀请新成员时请重新生成。此功能用于可恢复删除，不提供永久擦除。

## 参考另一位用户的配置

平台管理员可在 **平台管理 → 配置参考** 新建方案：先选择来源用户及其已加入的空间，点击预览，检查将分享的内容，再填写方案名称和说明并发布。来源设置若在预览后变化，需要重新预览。

可分享的内容包括业务菜单顺序和隐藏设置、首页显示开关、配置标签及目标占比、公共产品的市场自选。银行账号、余额、交易、持仓数量、原始文件和私人笔记不会复制；无法在公共目录识别的自定义产品不发布。

**自定义标签名称仍是要分享的文字。** 发布前请检查标签、方案名称和说明里是否包含家人姓名、私人用途或其他不适合共享的内容。发布后的方案面向平台登录用户，管理员可以下架。方案保存的是发布时的配置，来源以后调整不会自动改变已发布方案。

其他用户进入 **管理中心 → 配置参考**，点击「预览与选用」，查看实际菜单顺序、标签目标和自选产品，然后勾选想采用的部分：

| 选用部分 | 对当前设置的影响 |
| --- | --- |
| 个人菜单 | 替换个人业务菜单偏好，影响你使用的全部空间；平台管理菜单保持自己的设置。 |
| 首页显示 | 替换当前空间的首页显示开关。 |
| 标签与目标占比 | 只新增缺少的标签；同名标签保留原颜色和目标占比。 |
| 市场自选 | 只新增缺少的产品；已有自选保持原设置。 |

目标占比合计不能超过 100%。若新旧目标冲突，系统会拒绝整个采用操作，不会只改一半；先调整自己的目标占比，再重新预览采用。菜单或空间配置在预览后被修改时，也要刷新预览。

查看成员只能参考，不能采用配置。编辑成员可采用自己的菜单设置；首页、标签与市场自选等账簿共享配置由空间所有者或平台管理员维护。采用方案不会给你增加任何资产或交易。

## 找管理功能、调整菜单和查看名词

「管理中心」集中空间成员、邀请码、回收站、配置参考、导航偏好、名词帮助、汇率、适配状态、导出及隐私设置。平台管理员另有「平台管理」，可维护所有用户与空间、数据源和管理审计。

统一调整一级、二级、三级菜单，请进入 **管理中心 → 导航偏好**。各组菜单旁仍有小型设置图标，可快速调整本组；不再重复显示醒目的文字按钮。隐藏只是改变自己的入口显示，不是撤销他人的访问权限；需要时可以恢复默认。

不熟悉的术语可将鼠标停在有说明的文字上，或点击查看；触屏可长按，键盘可聚焦后查看。系统内置 **122 个术语**，也可在 **管理中心 → 名词帮助** 搜索。账户名、基金自定义名称等个人输入内容不会被自动解释成专业术语。

## 新增账户后如何看首页金额

普通银行卡开户时填「开户时的金额」和「金额对应日期」。例如今天开始记账，银行卡有 5000 元，填 5000 后会计入今日净资产；它是已有资产，不算今天新赚了 5000 元。没有昨天的余额记录时，昨结显示待补全，不能据此把 5000 元当作一天的收益。

期货、期权或选择机构权益计值的账户，填写的是**客户总权益**，通常需要从结算单或机构终端查看。保证金、累计入金、可提取金额与总权益是不同数字；已经包含在总权益里的保证金和期权价值不要再加一次。开户时需说明总权益包含哪些内容，并核对期权是否包含；可提取金额可另填，未知时留空。

如果此前只录过期货账户的期初现金、没有录总权益，首页会显示已记录资金部分，并提示补充机构总权益。这部分尚不能代表完整持仓价值和结算盈亏。可以到 **分析复盘 → 行情与结算** 补充机构权益记录，系统不会把总权益与旧期初重复相加。

遇到金额仍未进入汇总，可以按页面提示检查：

- 统计日期是否早于金额对应日期。
- 账户是否采用机构权益方式，但尚未提供该日可用的权益记录。
- 外币账户是否缺少相应日期的折算汇率；系统会显示原币金额，不会擅自按 1:1 折算。
- 持仓是否缺少可用净值、价格或历史确认份额。

首页「来源与缺口」可以查看依据。净资产变化包含收支和资金变动，不能直接当作投资收益。
