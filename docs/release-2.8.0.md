# 2.8.0 定投一次设置与基金日期体验

新建场外基金定投默认自动记账，复用基金默认扣款与费用设置，首次保存后即处理已到期期次。正常期次自动记录扣款，并在申购日正式净值及费用齐备后推算份额；等待净值或预计入账日不再要求逐期确认。费用未知需配置一次，不猜测费用。已停用或暂停的旧计划保留原选择。

日/周定投默认休市跳过，月定投默认顺延至共同开放日；渠道策略可调整。计划锚点与实际扣款日期分离，避免假期造成后续日期漂移。暂停和失败日期可排除。QDII 的申购日历、估值日期及净值披露分开处理，不将迟到的旧净值称为今日收益。

首页、持仓和定投页收紧信息层级，主要指标集中展示，低频选项折叠。正式净值对应的收益不会因份额来自自动推算而被隐藏，来源标记仍保留。正常自动进度移出待处理入口；可随时更正交易。长假行情新鲜度按已核实交易日判断，未知日历保留原始价格并显示覆盖限制。

参考项目审查及官方规则见[研究说明](research/fund-workflows-2.8.0.md)。采用独立实现，未复制其 AGPL 代码。保持0011数据库迁移基线，保留生产数据，未增加真实银行扣款或基金平台下单能力。

本地全量后端1152项及12子测试通过，前端119项通过；类型、格式、生产构建和15项发布保护检查通过。浏览器使用独立合成账簿，验证新定投默认自动开启、月周期默认顺延、账外扣款可直接保存、首次保存即生成自动等待期次、旧关闭设置保留，以及640像素表单局部滚动无页面横向溢出。
