# ADR 0003：V2 核算政策替换旧稿冲突

- 日期：2026-09-25
- 状态：V2 合成算例作为实现与测试基线；实际产品规则待样本固化

## 优先级

2026-09-25 上传的 V2 业务决议优先于 2026-09-16 旧设计。旧文档保留作为历史材料；开发若遇到冲突，不应把两个政策同时套用。

## 成本与费用

采用管理口径移动加权平均；买入相关费用进入取得成本，卖出费用减少处置净额。费用可以单独分析，但不能再从已经扣费的净收益重复减去。不把管理成本称为税务成本。

V2 A1 的金标准：初始现金 10,000，扣款 1,000，申购费用 10、确认价格 2、份额 495。确认时持仓公允价值 990，管理取得成本 1,000。以 2.04 全部赎回，赎回费 5，到账 1,004.80；最终现金 10,004.80，净收益 4.80。旧稿中把买入费先单独费用化、后续又从成本重复扣费的做法不再适用。

## 事实、估值与未来

基金申请、扣款、份额确认、净值归属日、净值披露日和资金到账分别保存。预计 T+1/T+2 只能产生待办，不能自动确认事实。红利低波是策略描述，不足以识别具体基金及份额类别。

实际贷款扣款 520、尚不知拆分时，现金已减少，待分配清算 520；净资产完整性受限。后续确认本金 500、利息 20 时清算归零，现金不再减少，负债减少 500，净资产只减少 20。

机构期货/期权权益快照与其覆盖范围内明细互斥贡献；保证金和名义本金不是额外资产。新快照吸收已经计入的资金流后，旧滚动调整必须被替换，不能重复叠加。

冻结与目标预留需要识别重叠资金；预留不减少净资产。购房贷款直付卖方不虚构银行曾收到贷款。计划、场景、预测不写入事实账本。

## 不确定值

未知成本、缺净值、缺汇率、XIRR 无解/多解均保留状态，不填 0。金额输入来自十进制字符串，数据库采用 NUMERIC，展示格式化不能改变原始财务事实。精度、舍入、方法版本与覆盖范围随计算记录一起保留。
