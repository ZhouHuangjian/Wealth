# 2.9.1 按日定投、账户金额与代管授权

## 定投按到期日处理

定投保存计划规则，不再预先创建未来一年的执行期次。后台按账簿时区定时扫描，当天到期才生成并处理；停机后会补齐遗漏的到期期次。扫描每五分钟运行一次，已记录的扣款不会重复入账，等待净值的份额仍会自动重试，无需逐期确认。

月定投遇休市顺延时，在实际开放日生成执行记录，保留原计划日期。未来 30/90/365 天资金预测继续按规则即时计算，不写入执行记录。普通周期收支和贷款原有排程不受这次变更影响。

旧版本预生成的未来定投期次，只在有原始生成证据、未修改、无交易、无业务引用且仍为待执行或系统休市跳过状态时收起。清理前保存完整审计记录；已执行、待确认、手动跳过、排除及证据不足的记录均保留。

## 期货账户金额

此前账户列表汇总账务分录，机构权益开户金额则保存于机构权益快照，因此期货账户会错误显示为零。现在期货、期权及采用权益快照的账户，列表按机构权益与之后可核对的资金收支显示，不再遗漏开户金额，也不重复加持仓或保证金。

列表标题为“账户金额”，逐行区分账面金额、机构总权益和盘中权益，并显示依据日期。独立现金余额仍保留原分录口径；权益不足以核对时保留缺口，不伪造零值。本次修复不补写现金分录或更改原开户金额。

## 管理员代管须由所有者允许

入口：**管理中心 → 隐私与安全 → 允许管理员代管此空间**。

- 新旧空间均默认关闭，平台管理员不能自行开启。
- 仅该空间所有者的普通账号可允许或撤销；编辑成员、查看成员与代管中的管理员不能修改授权。
- 允许后，管理员可代管读取、修改、维护账簿、下载文件与导出，并按既有功能整理配置参考；页面会明确说明范围。
- 关闭后，后续读取、修改、下载、导出及旧请求重试均重新检查并拒绝。已打开的管理员页面在请求被拒绝时清除；无请求时由定时和聚焦检查更新。
- 管理员仍可维护平台用户和空间生命周期，包含停用、删除、恢复及整空间回收站；这些操作与进入用户账簿代管区分。
- 来源空间撤销授权后，相关配置模板不再提供预览或继续应用。已经下载或已应用到其他空间的内容无法通过撤销授权追回。

迁移 `0012_workspace_admin_access` 增加两个默认关闭的授权字段，并为数据库业务数据永久删除函数增加授权检查。保留原有财务数据。旧版应用不识别新授权字段，迁移后不得直接回退旧镜像绕过权限边界。
