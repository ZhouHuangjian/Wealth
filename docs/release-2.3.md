## 本轮功能

- 产品元数据：根据产品代码及已选类型自动识别市场、币种、交易所；优先从公共目录补充基金类型。对代码歧义和未验证挂牌状态明确提示，允许用户手工指定规则。
- 基金日期：境内普通场外基金默认建议 T+1，QDII 建议 T+2，FOF 可建议 T+3，均明确属于未核对具体合同的估计。确认周期不等于净值披露周期或赎回到账周期；用户可以保存产品规则覆盖建议。
- 交易日：采用附有官方来源的已发布日历及基金截止时点，计算归属交易日、预期确认日。仅估算，不生成实际交易、确认份额或扣款；QDII 基金临时暂停申赎、境外节假日与夜盘交易日仍须按产品/机构实际记录核对。
- 导航：行情与结算迁入分析复盘，保留旧链接跳转；一级、二级、三级业务菜单支持个人排序、隐藏及恢复默认，服务器按用户保存，跨账簿沿用。隐藏不等于撤销访问权限，直接链接仍能打开；设置与恢复入口始终可达。
- 市场观察：增加常用指数和黄金候选，可浏览、筛选服务端公开缓存并多选加入自选。公开候选不是自动建立的用户持仓。
- 平台管理员：独立管理所有用户与账簿；创建/启停用户、重设他人密码、分配成员、进入他人账簿配置。操作始终使用管理员本人身份，不冒用他人登录；普通用户仍按成员权限及数据库 RLS 隔离。
- 数据源：管理员启停安全内置来源、调整各类产品优先级。报价、历史、搜索按来源实际能力依次尝试，源故障或无有效结果时切换；身份/币种校验不会因切换放宽。只有一个可用提供方的品类不能保证故障时仍有报价。

## 管理与安全边界

管理员身份使用后端用户权限判断，不靠用户名或前端按钮判断。已有 `admin` 账户只在本次部署时通过明确的运维命令授予平台权限；其他已有用户不会自动提升。新安装首次初始化的管理员拥有平台权限。

平台管理写入有幂等保护和乐观版本校验；管理员不能停用或降级自己的当前账号，不能通过管理界面跳过原密码要求修改自己密码。停用用户/重设密码会撤销旧会话。平台审计为数据库不可原地修改的记录；密码及原始密码请求不进入审计详情。

内置数据源仅开放允许列表的公开端点，不允许填写任意 URL、执行代码或上传提供方密钥。配置在每次刷新/联网查询读取，不依赖只在单个 Web 进程生效的永久缓存；已进行中的请求使用其开始时配置。
