# 网页远程设置联系人

在 Wealth「聊天助手 → 会话动态」选择已绑定的 Mac 和联系人；设备管理中的「远程管理」可调整设置。Mac 上的相知须运行，并开启网页远程管理，才能更新近况或处理操作；离线时可以查看上次同步的内容及时间。

会话动态可按页查看已接入联系人完整已读历史、媒体解析、逐条意图分析，以及最新候选回复和档案记忆摘要。完整消息和现有解析、分析会分批同步至绑定的 Wealth 服务器，进度区分本机读取与服务器存档。近况快照仍为最多 8 人各 30 条的预览，历史存档独立保存，不受该预览限制。原始图片和语音、习惯档案、API 密钥及模型服务地址保留在 Mac。关闭远程管理后，网页隐藏近况及相关操作结果；撤销设备绑定后不再展示该设备的快照。

每条消息下方按「分享 80%、其他 15%、表达不满 5%」展示可能的意图。比例是模型在不同理解之间分配的相对权重，合计 100%；不是经验证的真实概率，也不是情绪强度。“其他”表示未归入现有分类的可能含义。分析仍受该联系人的开关控制，可以在网页请求分析指定消息、识别媒体、刷新会话或生成候选回复。

微信内置表情和 Unicode 表情在 Mac 本地解析，不使用模型额度。自定义表情包复用图片识别及本地缓存，按此人的自动识图开关处理；相同媒体及识别模型复用缓存。原始媒体不随近况上传。

「模型中心」统一查看与调整回复及比较模型、图片和语音模型、分析和记忆模型，各功能仍可独立分配。联系人内的「模型设置」集中管理个人覆盖，图片和语音型号继承全局选择。每位联系人的自动草稿、自动识图、自动语音转写、意图分析、好感估计和记忆开关分别设置；个人模型覆盖可以恢复使用默认设置。好感百分比显示在姓名旁边。

在此人的「档案与记忆」中主动读取后，可以添加、修改、删除基础资料和记忆条目，修改摘要及待续话题，也可以让 Mac 使用已配置模型整理档案或压缩对话。人工修改仍保存在 Mac，优先用于后续回复。主动读取的档案和记忆、会话操作结果会作为命令回执保存在 Wealth，沿用现有 30 天清理周期；会话快照持续替换为最新的有界近况；完整历史在独立存档中持续保留，永久删除设备时一起清理。

网页只选择模型，不修改 API 地址、密钥或远程模型授权。首次接入模型服务仍在 Mac 设置中完成。Codex 候选模型来自这台 Mac 的可用模型目录，千问候选只出现在千问服务下。当前 Codex 接入支持文字与图片，语音使用已配置的千问或支持音频输入的兼容服务。

保存时会核对本机最新配置。若其他页面或 Mac 已修改，旧表单不会覆盖新设置，请刷新后重新调整。远程操作有执行回执；未连接的 Mac 会待其上线后处理，过期或撤销绑定的操作不会继续执行。网页命令不会发送微信消息。

配置协议 v2 向后兼容 v1：旧 Mac 仍可使用原有基础操作，新 Mac 遇到旧服务器暂时回退基础配置。2.14.7 的历史存档另用有序批次协议并新增四张存档表；旧客户端与服务器仍可使用原有近况功能。

Mac 的「读取历史」会后台续读本机当前可用的全部消息，不会自动开启长期监听。长历史分析分段整理并本地缓存，已知补读未完成时会要求先完成读取；分段并非仅分析最近 N 条。档案和记忆是精简资料，完整原文仍在本机及已开启的服务器存档中。微信补下载了早期记录后，可以在本机「信息处理」使用「重新扫描历史」。
