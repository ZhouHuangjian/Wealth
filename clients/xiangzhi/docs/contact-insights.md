# 联系人分析、基础库与记忆

## 独立选择模型

在设置中分别选择“意图与好感度分析模型”和“对话记忆模型”。它们与回复、图片、语音模型分开，可以使用千问、兼容 API 或 Codex 的具体型号。每个功能分别保存服务地址、密钥与远程处理许可；密钥留空时保留已保存值，不回显到网页。仅保存配置不调用模型。

在某个人的对话 → “信息处理”中控制该人的分析与记忆功能，也可为该人选择具体分析和记忆型号。开启 A 的功能不会开启 B 的功能。

## 意图与好感度

开启意图分析后，可以分析某一句已收到的消息。个人对话页面只展示百分比，不显示“质问”“关心”等意图类别；完整类别、依据与模型来源可在设置的分析详情中查看。好感度单独开关，展示根据当前互动整理的估计百分比。它们用于比较不同解读，不是对方真实心理的测量或经过校准的心理学概率。

已保存的分析留在本机，相同上下文和模型配置可复用结果。修改意图或好感度开关、对应模型、基础信息等相关配置后，旧分析会失效，需要重新分析；关闭开关也会隐藏对应信息。草稿生成继续参考已有的本人习惯档案。

## 对方基础库

打开“对方档案与记忆”，手动记录目前状况、兴趣爱好、偏好、已知事实、相处边界和计划。每条可记录来源，随时修改或删除。这些是当前联系人的背景，不会自动混入“我的习惯档案”。

## 本地记忆

“整理关键记忆”将当前联系人的对话压缩为摘要、关键事件与未完话题，保存在本机，重启后仍可使用。模型整理的信息先作为待确认线索，逐条确认后才成为可用的长期背景；不符合的线索可以忽略。已有记忆可以清除，对方基础库单独保留。

自动整理单独开启。新来信触发检查，累计至少 20 条未整理消息后才调用记忆模型；首次读取、历史补读与导入不会自动发起分析或记忆调用。历史内容可由你点击“整理关键记忆”处理。兼容 API 指向本机回环地址时可使用本地模型，无需开启远程处理；联系人选择 Codex 时则需允许该功能远程处理。

完整对话、基础库与记忆保存在当前 Mac；同步草稿不会上传这些原始信息。
