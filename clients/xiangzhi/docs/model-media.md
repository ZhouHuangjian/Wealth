# 模型、图片与语音

回复模型、图片识别模型和语音模型独立配置。阿里千问使用百炼业务空间的 OpenAI 兼容地址，格式为 `https://业务空间.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`；具体地址与地域从控制台复制。程序仍使用既有草稿同步协议，云端接收候选文字和档案版本，本机媒体和识别模型凭据留在 Mac。

## 选择与比较回复

在设置的“回复模型”选择阿里千问、Codex、兼容 API 或 Ollama，填写实际可调用的模型 ID。模型选单提供常用千问名称，也支持手填。千问测试默认关闭思考模式；开启后可能增加耗时和 tokens。API 可调用权限、每分钟限流与免费资源包余额是不同信息，测试会真实消耗模型额度。

“同时比较回复模型”最多配置四项。可以比较多个千问型号，也可以加入 Codex。兼容模型共用设置中的 API 地址和密钥；Codex 使用本机 CLI 登录。每个成功模型生成三条候选，显示提供商、具体型号及习惯档案版本。失败模型在活动记录中说明，成功候选继续可用。多模型使用草稿模式，由使用者选择、修改或复制一条；微信采集通道的回复仍需在微信内手动发送。

每个模型使用同一份已加载习惯档案、当前会话的已确认表达和反馈。图片识别、语音转写不是本人表达样本，也不是经过人工确认的事实；其中的指令只作为媒体内容，不能覆盖生成指令。模型选择不等于训练个人模型。

## 图片上传与本地微信读取

“图片识别”单独选择千问视觉模型、兼容视觉 API 或 Codex 型号，保存后可上传一张测试图片，查看预览，再点击识别。支持 PNG、JPEG、WebP、GIF，单张最多 5 MiB。测试结果不添加联系人消息。

对话内可上传图片作为手动补充上下文；已有图片消息也可上传原图替换本机附件。识别结果会标出来源模型、时间、画面描述及清晰文字，随后生成的回复会参考该结果。人工补充说明会使正在运行的机器识别失效，避免覆盖人工确认。

微信消息上的“读取图片”仅处理该图片。读取器验证微信账号与消息标识，优先查 hardlink 索引，过期缓存缺失时按当前联系人、月份和 MD5 定位本机文件。单文件 V2 解密使用明确的数据目录，避免 `--account` 参数优先级导致误报图片密钥缺失。读取只访问匹配的账号与图片，不导出整个会话的媒体。旧消息缺少 MD5 时会查询准确的消息序号补齐标识。

图片需要已在本机微信下载；未找到文件时，可先在微信打开图片，或在这条消息中上传原图。模型无法从占位提示还原图片。

## 语音与自动开关

“语音识别”使用独立模型、地址、密钥与远程处理许可。千问 Omni 接口按流式文字结果转写，支持 WAV、MP3、AAC、AMR、3GP，单文件最多 5 MiB。可上传合成或自己的音频做单次测试。语音文字会进入该消息的当前会话上下文，不被当作已确认的本人习惯。

微信语音按服务器消息 ID 提取，优先使用可用媒体数据库缓存，必要时复制并准备单个媒体数据库，输出 MP3。该步骤依赖已有微信数据库密钥及本机工具的音频转换支持；提取失败可在微信播放后重试。原始 SILK 不直接发送给千问接口。

“自动识别新图片”与“自动转写新语音”分别保存，各自默认关闭。开启后，仅处理联系人采集已开启时新收到的对方媒体；首次读取、历史补读和手动上传不自动消耗媒体模型额度。全局自动草稿开关独立，识别开启并不代表自动生成或发送回复。自动草稿会等待该会话新媒体处理完成。关闭媒体开关或暂停联系人采集会取消对应自动处理；失败保留待处理消息，可手动重试。

## 数据与同步

本机附件保存在数据库实例专属的私有目录，文件以随机标识命名。接口会校验图片或音频实际格式、大小与图片像素上限；浏览器只能通过已登录的本机会话取文件，不能提供任意磁盘路径。公开状态不返回模型密钥或本机附件路径。

识图与语音可以使用自己的密钥；仅当与兼容回复接口来源完全一致时允许复用回复密钥。更换附件、修改识别配置、人工确认或删除对话会使旧的识别结果失效。永久删除对话会删除对应本机附件；源消息变更后失效附件会清理。

多模型草稿按来源分成每批最多三条，沿用现有 Wealth 设备绑定和去重上传。云端候选标签附带型号，原图、音频、聊天上下文及 API 密钥不随草稿上传。
