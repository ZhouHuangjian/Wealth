# 相知 Mac 客户端

本机微信采集、习惯档案、候选回复生成及向 Wealth 上传草稿的工作台。此目录只包含程序和合成示例，不包含个人聊天、数据库、微信密钥、习惯档案或模型登录状态。

Mac 可双击 **启动相知.command**：首次自动准备项目依赖和构建，之后后台运行并打开浏览器；默认端口 `4351`，优先保留已有数据。重复点击复用同一实例，**停止相知.command** 只停止本入口创建的服务。详见 [Mac 一键启动](docs/local-launch.md)。以下手动命令继续可用。

需要 Node.js 22.13 或更高版本。在此目录执行：

```sh
npm ci
npm run build
SEED_DEMO=false npm start
```

默认工作台仅监听 `http://127.0.0.1:4317/`。不要将本机工作台直接暴露到公网。默认数据位于此目录下的 `private/`，可通过 `DATA_DIR` 指定已有实例的私有目录；切换代码目录时要继续使用原来的数据目录，避免误以为历史记录丢失。

在 Wealth 登录自己的账号，由管理员启用聊天功能；进入聊天助手创建设备，复制连接配置。在本机“设置”的草稿同步区域粘贴并保存；Wealth 配置保存后自动验证连接，也可手动“验证连接”。验证不上传草稿，之后可手动同步一批草稿核对。自动同步需要另行开启。完整流程见 [聊天助手说明](../../docs/chat-assistant.md)。

本机仍需要配置可用的微信读取工具和回复生成方式。程序不会自动安装或登录这些工具；微信密钥及模型登录留在本机。`PROFILE_MANIFEST_PATH` 可指定个人档案清单的绝对路径；未附带档案不会凭空继承开发者的个人习惯。所有草稿由使用者核对，网页与本机的“复制”均不代表向微信发送。

微信历史按批保存并记录断点。“已保存”表示已有消息可查看，只有“本机可用历史已完整读取”才表示读到当前本机历史末尾。续读失败会保留已保存的消息和进度；历史读完后的一次新增检查失败，也不会将历史进度改为未完成。适配器会分别处理 wx-cli 的游标与偏移分页，避免同时传入不兼容的参数；同一排序序号跨多页时仍会继续读取，不跳过剩余消息。

设置中可分别选择回复、图片与语音模型，包含阿里千问兼容接口和 Codex 图片输入；最多同时比较四个回复模型，每个模型提供三条候选并记录习惯档案版本。图片上传、微信单张图片读取和语音转写结果进入当前会话上下文。每位联系人可在对话的“信息处理”中单独选择回复模型、自动识图和自动语音转写；媒体开关独立且默认关闭。详见 [模型与媒体使用说明](docs/model-media.md)。

连接配置按数据库实例独立保存，清除即停用；显式恢复环境配置时才重新使用 `DRAFT_SYNC_URL` 与 `DRAFT_SYNC_TOKEN`。设备凭据仅授予验证连接及上传草稿的权限，撤销设备后失效，不等于网站登录密码。

```sh
npm test
npm run build
```

测试使用合成数据与临时数据库，不依赖真实聊天或微信账号。

情绪与意图分开显示，互动估计可展开六维原话依据；本人回复支持按当时上下文及习惯档案复盘。对话记忆支持有来源的事件状态和个人修改，完整历史列表按可视区域挂载。详见 [交流分析与回复复盘](docs/communication-review.md)。
