# 相知 Mac 客户端

本机微信采集、习惯档案、候选回复生成及向 Wealth 上传草稿的工作台。此目录只包含程序和合成示例，不包含个人聊天、数据库、微信密钥、习惯档案或模型登录状态。

需要 Node.js 22.13 或更高版本。在此目录执行：

```sh
npm ci
npm run build
SEED_DEMO=false npm start
```

默认工作台仅监听 `http://127.0.0.1:4317/`。不要将本机工作台直接暴露到公网。默认数据位于此目录下的 `private/`，可通过 `DATA_DIR` 指定已有实例的私有目录；切换代码目录时要继续使用原来的数据目录，避免误以为历史记录丢失。

在 Wealth 登录自己的账号，由管理员启用聊天功能；进入聊天助手创建设备，复制连接配置。在本机“设置”的草稿同步区域粘贴并保存，再手动同步一批草稿核对。自动同步需要另行开启。完整流程见 [聊天助手说明](../../docs/chat-assistant.md)。

本机仍需要配置可用的微信读取工具和回复生成方式。程序不会自动安装或登录这些工具；微信密钥及模型登录留在本机。`PROFILE_MANIFEST_PATH` 可指定个人档案清单的绝对路径；未附带档案不会凭空继承开发者的个人习惯。所有草稿由使用者核对，网页与本机的“复制”均不代表向微信发送。

连接配置按数据库实例独立保存，清除即停用；显式恢复环境配置时才重新使用 `DRAFT_SYNC_URL` 与 `DRAFT_SYNC_TOKEN`。设备凭据仅授予上传草稿的权限，撤销设备后失效，不等于网站登录密码。

```sh
npm test
npm run build
```

测试使用合成数据与临时数据库，不依赖真实聊天或微信账号。
